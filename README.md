# TechsoftAI Assistant

Mobil öncelikli PWA tabanlı AI iş asistanı.

## V1
- Mobil PWA arayüzü
- Kullanıcı giriş demo ekranı
- Ana ekran / günlük özet
- Görev listesi ve lokal saklama
- AI asistan komut alanı
- Desteklenen tarayıcılarda sesli komut denemesi
- Service Worker ile temel offline desteği

## Yol haritası
ASP.NET Core API + SQL Server, gerçek kimlik doğrulama, AI API, görev/hatırlatma motoru, push bildirimleri, Outlook Takvim ve WhatsApp Business entegrasyonu.

> Not: V1 login ve AI cevapları prototiptir; üretim güvenliği için backend/API eklenecektir.
